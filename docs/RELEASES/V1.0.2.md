# Codex Keeper for Windows V1.0.2

## 修复

- 补全额度快照恢复时间识别；缺少明确重置时间时，按额度窗口长度计算保守的最晚等待时间，并在恢复后重新核对实时额度。
- 任务勾选授权与自动续跑资格分开。额度记录不完整时可以保存选择，但账户、任务和额度状态未核实前不会续跑。

## 要求

- Windows 10/11 x64。
- 已安装并登录 Codex。
- 保活需要账户提供 `gpt-6-luna`。

安装包未签名；下载后请核对随附的 SHA-256 文件。安装步骤见 [Windows 安装说明](../INSTALL-WINDOWS.md)。

## English

### Fixes

- Recovery windows are retained when Codex omits an explicit reset timestamp. Keeper waits for the conservative window-duration deadline and then checks live quota again.
- Task selection is saved independently from resume eligibility. Incomplete quota records can be selected, while automatic resume remains blocked until account, task, and quota state are verified.

Requires Windows 10/11 x64, Codex installed and signed in, and an account that offers `gpt-6-luna` for keep-alive. The installer is unsigned; verify the accompanying SHA-256 file. See the [Windows installation guide](../INSTALL-WINDOWS.en.md).
