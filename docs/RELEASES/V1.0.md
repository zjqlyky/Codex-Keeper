# Codex Keeper for Windows V1.0

首个 Windows x64 安装版。

## 包含内容

- 额度概览、每日计划和系统托盘运行。
- 从本机 Codex 记录读取项目与任务，用户可分别勾选保活项目和允许自动续跑的任务。
- 安装程序默认按当前 Windows 用户安装，不需要管理员权限。
- 保留已选择的项目和任务设置；卸载不会删除 `%LOCALAPPDATA%\CodexKeeper\settings.json`。

## 使用要求

- Windows 10/11 x64。
- 已安装并登录 Codex。
- 保活需要账户提供 `gpt-6-luna`。

安装包未签名；下载后请核对随附的 SHA-256 文件。详细步骤见 [Windows 安装说明](../INSTALL-WINDOWS.md)。

## English

First Windows x64 installer release.

- Usage overview, daily schedule, and system-tray operation.
- Reads local Codex projects and tasks; project keep-alive and task auto-resume are selected separately.
- Per-user installation does not require administrator rights.
- Preserves project and task selections. Uninstall leaves `%LOCALAPPDATA%\CodexKeeper\settings.json` in place.

Requires Windows 10/11 x64, Codex installed and signed in, and an account that offers `gpt-6-luna` for keep-alive. The installer is unsigned; verify the accompanying SHA-256 file. See the [Windows installation guide](../INSTALL-WINDOWS.en.md).
