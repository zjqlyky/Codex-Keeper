# Codex Keeper for Windows V1.0.1

## 修复

- 任务恢复列表现在使用 Codex 侧边栏中的当前任务名称。重命名会在 Keeper 刷新后保持一致。

## 要求

- Windows 10/11 x64。
- 已安装并登录 Codex。
- 保活需要账户提供 `gpt-6-luna`。

安装包未签名；下载后请核对随附的 SHA-256 文件。安装步骤见 [Windows 安装说明](../INSTALL-WINDOWS.md)。

---

## English

### Fix

- The task recovery list now uses the current task name shown in the Codex sidebar, including after a rename and refresh.

Requires Windows 10/11 x64, Codex installed and signed in, and an account that offers `gpt-6-luna` for keep-alive. The installer is unsigned; verify the accompanying SHA-256 file. See the [Windows installation guide](../INSTALL-WINDOWS.en.md).
